# El_Instituto

Este es un puzzle (tambien conocido como un "webpuzzle") con 3 niveles, Nivel 0, 1 y 2. Deberia ser facil! (todo esta en ingles tristemente). 

Tienes que encontrar codigos que debes poner en el link para pasar al siguiente nivel y es recomendable intentar resolverlo con varias personas (o el colegio entero) a la vez para que sea mas facil.

Entra el instituto. Dime lo que encuentras al Final
https://infinitude.nekoweb.org/precipicio.html
